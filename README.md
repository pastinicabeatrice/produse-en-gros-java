# Produse en-gros

Produse vândute en-gros, cu discount calculat după cantitate.

## Funcționalități

- interfața `Saleable` și clasa abstractă `Product`
- `EnGrosProduct`, cu discount în funcție de cantitate
- valoarea înainte și după discount
- clonare
- stoc static ordonat (`LinkedHashMap`) și afișarea lui

## Rulare

Proiect Eclipse; se poate deschide și în IntelliJ IDEA. Clasa principală este `app.main.Main`.
